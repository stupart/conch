# Conch plugin template

`conch install-plugin` materializes this shared Claude Code/Codex template into the stable plugin distribution directory, refreshes its instruction prose, and writes the generated absolute-path MCP declaration into `.mcp.json` (Claude Code) and `.codex-mcp.json` (Codex), and `bin/conch`, which runs the same conch from a session's shell (`conch agent …`, `conch bug`).
